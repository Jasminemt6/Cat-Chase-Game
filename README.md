Welcome to Cat Chase!

You're a cat running through a forest after a mouse. Jump over blocks, duck under floating ones, and catch the mouse before it gets away.

![Screenshot](<Screenshot 2026-10-25 at 1.06.40 PM.png>)



CONTROLS:
Space = Start / play again
Up Arrow = Jump
Down Arrow (hold) = Duck

HOW THE GAME WORKS:
The cat slowly gains speed on the mouse as you run.
Hitting a block wil slow you down, and the mouse pulls ahead.
Catching the mouse would give you a point, and each run slowly gets faster!
If the mouse gets too far ahead, it escapes and the game ends.

HOW TO RUN:
Install Python3
Install pygame ('pip install pygame')
Download this repository
Run the game ('python cat_chase.py')
